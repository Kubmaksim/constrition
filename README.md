# SIRE Construction - Шаблон сайта на React + Tailwind CSS

Современный, полностью структурированный шаблон сайта строительной компании на React, Tailwind CSS с правильной архитектурой и best practices.

## 🚀 Быстрый старт

### Установка зависимостей

```bash
npm install
```

### Запуск проекта в режиме разработки

```bash
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173) в браузере.

### Сборка для продакшена

```bash
npm run build
```

### Просмотр собранного проекта

```bash
npm run preview
```

## 📁 Структура проекта

```
sireconctruction/
├── public/                 # Статические файлы
├── src/
│   ├── components/         # Переиспользуемые компоненты
│   │   ├── Nav.jsx        # Компонент навигации с мобильным меню
│   │   ├── Footer.jsx     # Компонент футера
│   │   └── sections/      # Секции страниц
│   │       ├── Hero.jsx
│   │       ├── Features.jsx
│   │       ├── CTA.jsx
│   │       └── ...
│   ├── pages/             # Страницы приложения
│   │   ├── Home.jsx
│   │   ├── About.jsx
│   │   ├── Services.jsx
│   │   ├── Projects.jsx
│   │   └── Contact.jsx
│   ├── hooks/             # Кастомные хуки
│   │   └── useScrollToTop.js
│   ├── utils/             # Утилиты и вспомогательные функции
│   │   ├── constants.js
│   │   └── helpers.js
│   ├── App.jsx            # Главный компонент приложения
│   ├── main.jsx           # Точка входа
│   └── index.css          # Глобальные стили и Tailwind
├── index.html
├── package.json
├── vite.config.js
├── tailwind.config.js     # Конфигурация Tailwind CSS
└── postcss.config.js      # Конфигурация PostCSS
```

## 🎨 Особенности

- ✅ **Современный стек**: React 18, Vite, Tailwind CSS 3
- ✅ **Маршрутизация**: React Router v6
- ✅ **Адаптивный дизайн**: Mobile-first подход
- ✅ **Правильная архитектура**: Разделение на components, pages, hooks, utils
- ✅ **Модульные секции**: Каждая секция - отдельный компонент
- ✅ **Мобильное меню**: Адаптивная навигация с анимациями
- ✅ **Best practices**: Чистый код, переиспользуемые компоненты
- ✅ **Готовые страницы**: Home, About, Services, Projects, Contact

## 🛠️ Кастомизация

### Цвета
Цвета можно изменить в `tailwind.config.js`:

```js
colors: {
  primary: {
    // Ваши цвета
  }
}
```

### Константы
Контактная информация и другие константы находятся в `src/utils/constants.js`

### Стили
Глобальные стили и утилитные классы в `src/index.css`

## 📱 Адаптивность
